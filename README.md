# Desktop Dog

A little dog that lives on your desktop, made with Godot.

## Features

- Walks around your desktop and bounces off the screen edges
- Notices your cursor and looks toward it
- Can be dragged around with your mouse
- Occasionally stops to rest
- Reacts to petting with floating hearts (Only if you are holding the left button on the mouse)
- Has an affection counter and different moods (In Godot Output)

## Built with

- Godot Engine
- GDScript

## Running the project

1. Clone this repository.
2. Open Godot and import the project.
3. Run the project using F6 or F5.
